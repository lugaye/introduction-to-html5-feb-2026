🚀 Week 1: The Digital Business Card Challenge
"Your first step into a larger world."
Welcome, Future Developer! This week, we are moving from being "web consumers" to "web creators." You aren’t just browsing the internet anymore; you are building the foundation of it.

Your mission is to create a Digital Business Card. This is a simple, clean, and effective one-page website that introduces you to the world.

🎯 The Mission Objective
Create an index.html file that tells us who you are. No fancy styling yet—this week is all about the skeleton (structure) of the web.

🏗️ Requirements (The "Must-Haves")
To pass the automated grader, your code must include:

A Semantic Header: Use an <h1> tag for your name.

An About Me Section: A <p> (paragraph) tag with a 2-line bio.

The "Skill Stack": An <ul> (unordered list) containing at least 3 skills or hobbies.

Visual Identity: An <img> tag that displays a profile picture (you can use a placeholder like https://via.placeholder.com/150).

External Connection: A link (<a> tag) to your LinkedIn, Twitter/X, or GitHub profile.

🛠️ Step-by-Step Instructions
Step 1: Claim Your Repo
Click the GitHub Classroom Invitation Link provided on the LMS. GitHub will automatically create a private repository for you called week-1-intro-to-html-[your-username].

Step 2: Clone & Open
Open your terminal (or Git Bash) and bring the code to your computer:

Bash
git clone [YOUR_REPO_URL]
cd [YOUR_REPO_NAME]
code .
(If code . doesn't work, just open the folder in VS Code manually!)

Step 3: Start Coding
Create a new file named exactly index.html.

Pro Tip: Type ! and hit Tab in VS Code to generate the HTML boilerplate automatically!

Step 4: The Content
Inside the <body> tags, start building. Be creative!

Challenge: Can you add a second heading (<h2>) for your "Experience" section?

Fun Fact: The alt attribute in your <img> tag isn't just for show—it helps visually impaired users understand your site. Always include it!

🤖 How to Get the "Green Checkmark"
This course uses Automated Grading. Every time you "Push" your code to GitHub, a robot will check your work.

Save your file.

In your terminal, run these three magic commands:

Bash
git add .
git commit -m "Added my business card content"
git push origin main
Go to your repository on GitHub.com and click the "Actions" tab.

If the light is Green, you passed! ✅

If the light is Red, click on the "Autograding" job to see what's missing. ❌
